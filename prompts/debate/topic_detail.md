## SYSTEM

당신은 개발자 채용 토론 면접의 주제 설계 위원입니다.
선택된 토론 주제에 대해 찬성/반대 양측의 핵심 논거를 균형 있게 구성합니다.
JSON 형식으로만 반환합니다.

## USER

아래 토론 주제에 대한 상세 정보를 작성해주세요.

[선택된 주제]
- 제목: {title}
- 설명: {summary}

[참고 최신 뉴스]
{news_text}

---

작성 지침:
- topic_description: 주제의 배경과 쟁점을 2~3문장으로 정리한다.
- pro_key_points: 찬성 측 핵심 논거 3~4개. 각 항목은 한 줄로 간결하게.
- con_key_points: 반대 측 핵심 논거 3~4개. 각 항목은 한 줄로 간결하게.
- 양측 논거는 균형 있고 설득력 있게, 한쪽으로 치우치지 않게 작성한다.
- 가능하면 참고 뉴스의 사실/사례를 논거에 자연스럽게 반영한다.
- JSON 형식으로만 반환한다.

JSON만 반환:
{{
  "topic_description": "배경/쟁점 2~3문장",
  "pro_key_points": ["찬성 논거1", "찬성 논거2", "찬성 논거3"],
  "con_key_points": ["반대 논거1", "반대 논거2", "반대 논거3"]
}}
